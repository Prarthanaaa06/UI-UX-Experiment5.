# UI-UX-Experiment5

## Aim:
To identify user pain points, write UX problem statements, select suitable research methods, and create user personas for two different UX project scenarios.


## Algorithm:

1. Select two different UX project scenarios.
2. Identify the target users and their major pain points.
3. Write 1–2 UX problem statements using the given template.
4. Select appropriate UX research methods for each scenario.
5. Justify why the selected research methods are suitable.
6. Create at least two user personas for each scenario.
7. Include demographics, goals, behaviors, pain points, and motivation for each persona.
8. Compile all the findings into a UX lab report.
9. Mention the GitHub repository URL in the submission.
